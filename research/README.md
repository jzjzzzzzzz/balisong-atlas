# Research library

This directory is the auditable research record for the Balisong Atlas paper **Between Two Handles**. It separates source discovery, full-text status, claim review, image rights, and public prose.

- `library/manifest.csv` records access, rights, hashes, and review scope.
- `library/raw/` is intentionally ignored. It contains only lawfully acquired open-access research copies and is not published with the code.
- `library/notes/` contains public-safe analytical notes. Controlled technical, operational, purchasing, and measurement content is recorded only as excluded, never copied.
- `source_matrix.csv` evaluates candidates; `claim_evidence_matrix.csv` separates fact from interpretation.
- `figure_manifest.csv` controls public image rights.
- `references.bib` is the citation-key registry.

AI assisted discovery, OCR cleanup, source classification, code, and draft structure. It is not a historical source. Every cited proposition must be checked against an acquired primary text, official record, institutional page, or clearly identified scholarly publication.
