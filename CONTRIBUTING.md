# Contributing

Contributions must preserve evidence traceability, bilingual clarity, rights metadata, and safe public visualization constraints.

## Development

```bash
make bootstrap
make lint
make typecheck
make test
corepack pnpm build
```

Add an Alembic migration for every database change. Add tests for policy boundaries and state transitions. Never add credentials, real technical dimensions, engineering drawings, operational tutorials, acquisition links, restricted originals, or usable object models to fixtures.

## Pull requests

- Explain the research or product problem.
- Identify schema/API/publication-policy changes.
- Add/update English and Chinese interface copy.
- Include actual commands run and their results.
- Do not describe unavailable capabilities as verified.

AI-generated code or prose must be reviewed by the contributor. AI output cannot be committed as historical evidence.

Large research copies belong in ignored content-addressed storage, never Git. Commit bibliographic metadata, access/rights state, hashes, and review notes instead. Running the collector does not authorize ingestion or publication.
