# Interface design references

The `reading-room-concept-*.png` files are AI-generated interface concepts used
only as visual layout references. Their sample source rows, dates, institutions,
and citations are synthetic placeholder copy and **must not be treated as
historical evidence or imported into the research corpus**.

The `reading-room-implementation-*.png` files are browser screenshots of the
implemented interface. Public source metadata in the implementation comes from
the reviewed, public-safe register in `apps/web/lib/research-library.ts`.

Concept and implementation images are project-design artifacts, not historical
source assets. They are not exposed as archive evidence.

`kinetic-era-geometry-comparison.png` is a browser-rendered QA contact sheet for
the five runtime geometry families. It verifies that period selection changes
handle treatment and central silhouette, not only color. The labels describe
research frames and do not assert exact historical replicas.

`kinetic-showcase-source-led-concept.png` is an AI-generated layout concept for
the evidence dossier, period rail, and source-folio rhythm. Its object, dates,
book titles, and body copy are synthetic design material and are **not source
records**. The implementation deliberately replaces all concept copy with the
tracked research register and its uncertainty states.

`kinetic-showcase-source-led-section.png` and
`kinetic-showcase-source-led-mobile-zh.png` are browser screenshots of the
implemented bilingual section. `kinetic-showcase-source-led-implementation.png`
captures the surrounding timeline page. The public-domain cover thumbnails in
those screenshots are bibliographic navigation assets documented in
`docs/RIGHTS_AND_ATTRIBUTION.md`; they are not object-form evidence.
