# Source evaluation

Tier indicates source type and editorial/provenance context—not truth.

- **A:** primary archives, contemporaneous records, museum catalogs/object records, original historical patents/catalogs as historical material.
- **B:** peer-reviewed papers, academic books, university/formal research institute publications.
- **C:** edited reliable secondary material, formal media/design publishing, clearly sourced cultural-institution articles.
- **D:** unclear web articles, forums/social posts, unverifiable testimony, recursive reposts without origin.

Reviewers separately assess creator/institution, date, access path, preservation snapshot, source family, directness, independence, bias, limitations, rights, and whether the item actually supports the specific proposition.
